# Overview

**پیش‌بین (Pishbin)** — کوپایلوت هوشمند تصمیم‌سازی مالی برای کسب‌وکارهای کوچک و متوسط ایرانی.

هدف محصول: یکپارچه‌سازی داده‌های مالی پراکنده (فاکتور، چک، رفتار پرداخت مشتری) و نمایش اثر تصمیم امروز روی ۳۰ روز آینده نقدینگی، طوری که صاحب کسب‌وکار مجبور نباشد خودش تنها CFO خودش باشد.

## پشته فنی
- **بک‌اند:** FastAPI + SQLAlchemy + PostgreSQL + JWT (access/refresh/2FA/reset) — `backend/`
- **فرانت‌اند:** Next.js 15 (App Router) + TypeScript + Tailwind + Recharts + Prisma client — `frontend/`
- **دیپلوی:** Docker Compose (postgres + backend + frontend)، nginx برای prod — `docker-compose*.yml`, `nginx/`

## دامنه‌های اصلی محصول
0. **چند کسب‌وکار/شعبه:** هر کاربر می‌تواند چند Business داشته باشد و بین‌شان سوییچ کند؛ همه حساب‌ها به یک Business تعلق دارند — [[entities/business]]
1. **مالی شخصی/کسب‌وکار پایه:** حساب‌ها (account)، تراکنش‌ها (transaction)، بودجه (budget)، هدف مالی (goal) — [[entities/account]], [[entities/transaction]], [[entities/budget]], [[entities/goal]]
1.5. **چک (صادره/دریافتی):** موجودیت درجه‌یک با وضعیت وصول و شماره صیادی؛ چک‌های در جریان به‌عنوان رویداد نقدی آینده در پیش‌بینی ظاهر می‌شوند (استعلام واقعی صیاد هنوز فاز بعد است) — [[entities/check]]
1.6. **آشتی‌سازی بانکی:** آپلود CSV صورت‌حساب بانک و تطبیق خودکار ردیف‌ها با تراکنش‌های ثبت‌شده (read-only، گزارش بی‌تطبیق‌ها) — [[concepts/reconciliation]]
1.7. **مشتری و فاکتور:** ثبت مشتری و فاکتور فروش، امتیاز رفتار پرداخت مشتری (تأخیر فاکتور + نرخ چک برگشتی) — [[entities/customer]], [[entities/invoice]]
2. **پیش‌بینی نقدینگی و هشدار کسری:** موتور یکپارچهٔ رویدادهای قطعی (چک+فاکتور) + روند تاریخی، هشدار زودهنگام کسری نقدینگی — [[concepts/forecast]]
3. **پرداخت:** درگاه زرین‌پال — [[entities/payment]]
4. **پیام‌های بانکی:** پارس پیامک بانکی به تراکنش — [[entities/banking-message]]
5. **تراکنش تکرارشونده:** قالب درآمد/هزینه دوره‌ای — [[entities/recurring-transaction]]
6. **API Key:** دسترسی برنامه‌نویسی — [[entities/api-key]]
7. **احراز هویت:** JWT + 2FA (TOTP) — [[concepts/auth]]

## نکته وضعیت فعلی محصول
صفحات dashboard و investors هنوز روی مفاهیم قدیمی SaaS استارتاپی (burn rate، runway، ARR/MRR) هستند و فقط نام‌گذاری‌شان به پیش‌بین تغییر کرده؛ بازطراحی منطق/دیتامدل برای پوزیشنینگ SME (فاکتور، چک، پیش‌بینی نقدینگی) هنوز انجام نشده — نیازمند تصمیم/کار جداگانه.
اتصال به سامانهٔ مودیان (صورتحساب الکترونیکی مالیاتی) و استعلام واقعی سامانهٔ صیاد چک هنوز پیاده نشده‌اند — فاز بعد.
ML واقعی برای پیش‌بینی (LSTM/ARIMA) هنوز پیاده نشده؛ مدل فعلی رویدادهای قطعی + روند تاریخی است (مدل پایه).
